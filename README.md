# مهرینه — اندروید بومی Kotlin + XML

این مخزن یک پروژه **Native Android** است: Kotlin + Android XML، بدون Flutter و بدون WebView. یک مخزن مستقل و قابل بارگذاری در GitHub.

## امکانات قابل اجرا (روی همان دستگاه)
- داشبورد فارسی راست‌به‌چپ، اعلام حال، درخواست کمک و تماس با شماره‌های ذخیره‌شده
- چهار تم رنگی و چهار اندازه متن
- تقویم نمایشی، ثبت و نمایش یادآوری‌ها، خواندن آن‌ها با Android Text-to-Speech
- پنل خانواده در همان دستگاه با نمایش وضعیت و سفارش آزمایشی
- آموزش‌های مرحله‌ای و شبیه‌ساز سه‌مرحله‌ای خرید
- چت فرمان‌محور، ورودی گفتاری در صورت پشتیبانی سرویس تشخیص گفتار گوشی، پاسخ صوتی
- ثبت سفارش آزمایشی فقط با تأیید کاربر
- میان‌بر برنامه‌های نصب‌شده

## محدودیت‌های مهم
- این نسخه **بک‌اند، حساب واقعی، اعلان پوش، اعلان زمان‌بندی‌شده، ویدئوی واقعی، خرید واقعی، چت هوش مصنوعی آنلاین و همگام‌سازی بین دستگاه‌ها ندارد**. این‌ها برای محصول نهایی نیاز به توسعه و سرویس مجزا دارند.
- داده‌ها در SharedPreferences محلی هستند. پنل خانواده وضعیت همین گوشی را نشان می‌دهد؛ به گوشی دیگر پیام نمی‌فرستد.
- کیفیت و پشتیبانی صدای فارسی و گفتار به متن به سرویس‌های نصب‌شده گوشی بستگی دارد.
- هنوز APK روی گوشی واقعی تست نشده؛ نخستین ساخت GitHub Actions نیز باید تأیید شود.

## ساخت APK بدون Android Studio
1. محتویات پوشه پروژه را در ریشه یک مخزن GitHub جدید آپلود کنید (پوشه `.github` را فراموش نکنید).
2. Actions > Build native Kotlin APK > Run workflow.
3. بعد از سبز شدن اجرا، بخش Artifacts > `mehrineh-native-debug-apk` را دریافت و استخراج کنید.
4. `app-debug.apk` را روی گوشی تست نصب کنید. این APK امضای Debug دارد و برای انتشار عمومی مناسب نیست.

## ساخت محلی
Android SDK 35، JDK 17 و Gradle 8.10.2 لازم است. دستور: `gradle :app:assembleDebug`.

## نکات امنیتی
مجوزهای موجود: اینترنت، میکروفن (در صورت استفاده از تشخیص گفتار)، اعلان‌ها (برای توسعه آتی). مجوز میکروفن توسط سرویس تشخیص گفتار مدیریت می‌شود. برنامه هیچ داده‌ای را به سرور اختصاصی مهرینه ارسال نمی‌کند. فایل APK را پیش از نصب از نظر منشأ و هشدارهای امنیتی بررسی کنید.
